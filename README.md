# ИИ-Корпорация — центр управления

Интерактивный дашборд, наглядно показывающий работу мультиагентной ИИ-системы:
оргструктура из 10 агентов в 6 отделах, анимированный поток задач по конвейеру,
живой журнал событий и метрики в реальном времени.

## Два режима

- **Симуляция** — демонстрация потока задач без внешних вызовов, с авто-режимом.
- **Реальные модели** — каждый этап выполняет настоящая LLM через локальный
  LiteLLM-шлюз; ответы агентов попадают в журнал.

## Состав

| Папка | Что это |
|---|---|
| `app/` | Дашборд: React + TypeScript + Vite + Tailwind + shadcn/ui |
| `litellm-server/` | Шлюз LiteLLM: конфиг агентов, шаблон ключей, скрипт запуска |

## Быстрый старт (демо)

```bash
cd app
npm install
npm run dev
```

Откройте адрес из консоли — режим «Симуляция» работает сразу.

## Режим реальных моделей

```bash
cp litellm-server/.env.example litellm-server/.env   # вставить свои API-ключи
litellm-server/start.sh                              # шлюз на :4000
```

Затем переключите дашборд на «Реальные модели». Подробная таблица
агентов и ключей — в [litellm-server/README.md](litellm-server/README.md).
