# AGENTS.md — глобальные правила для всех агентов проекта

## Иерархия

Владелец (Анастасия) → AI CEO → департаменты. Владелец находится НАД конвейером, не внутри него.

## Законы проекта

1. **Не создавай функцию, пока не понятно, какую дорогую работу она заменяет или какой доход создаёт.**
2. Задачи — только по `schemas/task.schema.json`. «Изучи и предложи что-нибудь» запрещено.
3. Исполнитель и проверяющий — всегда разные роли. Ревью кода — не автором кода.
4. Решение принимается по sha256 просмотренной версии артефакта.
5. `accepted` = принят текстовый результат, не запуск продукта/продаж/публикации.
6. Рискованные действия (`human_approval: true` + список в `config/company.json → human_only_actions`) — только с подтверждением владельца.
7. Платные вызовы моделей заблокированы, пока budget = null (лимит не задан владельцем).
8. Конфиденциальные и персональные данные — только утверждённый контур (`config/model-router.json → data_policy`). Содержимое частных консультаций — никогда.
9. Production: только Git → тесты → review → staging → approval → deploy → healthcheck. Модели не получают root.
10. Прохождение тестов не называть аудитом безопасности.

## Структура

- `config/` — tenant и model router (компания как код)
- `org/agents.json` — роли и контракты
- `schemas/` — протоколы
- `blueprints/` — переносимые рецепты компаний
- `src/` — ядро (журнал)
- `backlog/` — задачи JSON, `outputs/` — результаты Markdown
- `data/` — SQLite и неизменяемые копии артефактов (не редактировать вручную)
- `docs/` — ADR и карта происхождения
