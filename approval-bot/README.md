# Approval Bot — @asolomina_bot

Постоянное правило работы (согласовано с владельцем 2026-11-05):
**все задачи и решения, требующие согласования владельца, отправляются в Telegram-бот
с кнопками действий** (например: ✅ Согласовать / ❌ Отклонить / 🚀 Запустить в работу / 📄 Подробнее).

## Как это работает

- `approvals.py send "Заголовок" "Текст" "Кнопка1,Кнопка2"` — отправить запрос.
- `approvals.py poll` — обработать ответы (запускается cron каждую минуту).
- `approvals.jsonl` — append-only audit log с hash-chain (как в целевой архитектуре audit_logs).
- `state.json` — offset Telegram и chat_id владельца.
- `.env` — токен бота (gitignored, никогда не коммитить).

## Ограничения локальной версии

- Работает, пока включён Mac (cron опрашивает Telegram каждую минуту).
- При переезде Founder AI OS на Spain-узел механизм становится серверным;
  формат запросов и audit log сохраняется.

## Безопасность

- Пишет боту — только владелец; решения фиксируются с username и timestamp.
- Токен даёт полный контроль над ботом: при подозрении на утечку — /revoke у @BotFather и замена в .env.
